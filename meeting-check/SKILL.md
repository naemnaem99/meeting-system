## 액션 아이템 완료 처리 스킬

### 팀 정보
- **팀원:** 소정, 하영, 해냄, 유진
- **Notion DB:** `collection://de7bdeac-d0b4-821e-96c7-0704ab267ee1` (HANCOM D조_한컴 > 1.회의록)

---

### 1단계: 입력 수집

사용자에게 다음을 요청한다:

```
이름이 뭐예요? (소정 / 하영 / 해냄 / 유진)
어떤 회의록이에요? (날짜 입력 또는 "최신")
뭘 완료했어요? (할 일 내용 입력)
```

---

### 2단계: Notion 회의록 조회

`mcp__claude_ai_Notion__notion-search`로 해당 날짜 회의록 찾기.

찾은 페이지를 `mcp__claude_ai_Notion__notion-fetch`로 전체 내용 가져오기.

---

### 3단계: 액션 아이템 찾기

페이지 본문의 "액션 아이템" 테이블에서:
- **담당자 = 입력한 이름**
- **할 일 = 입력한 내용 (부분 일치 가능)**

인 행 찾기.

일치하는 항목 없으면 사용자에게 알리고 중단.

---

### 4단계: Notion 업데이트

`mcp__claude_ai_Notion__notion-update-page`로 테이블 업데이트:

찾은 항목의:
1. 할 일 앞뒤에 `~~` 추가 (취소선)
2. 상태를 `완료 ✅`로 변경

형식:
```
| 해냄 | ~~회의록 시스템 개발~~ | 2026-07-28 | 완료 ✅ |
```

---

### 5단계: 완료 보고

```
✅ 완료 표기됨:
- [할 일]
- 담당자: [이름]
- 회의록: [Notion 페이지 링크]
```
