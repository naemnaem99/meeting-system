# 완료한 일 표기 스킬

Notion 회의록의 액션 아이템 상태를 "완료"로 자동 업데이트합니다.

---

## 🎯 역할

완료한 업무를 입력하면 Notion 회의록에 자동으로 상태가 "완료 ✅"로 표기됩니다.

---

## 사용자

각 팀원 (할 일 완료할 때마다)

---

## 사용 방법

### 명령어

```
/meeting-check
```

또는: "할 일 완료" / "업무 완료"

### 입력 정보

**1단계: 이름**
```
해냄
```

**2단계: 회의 날짜**
```
2026-07-28
또는
최신
```

**3단계: 완료한 할 일**
```
회의록 시스템 개발
```

### 결과

Notion 회의록이 자동으로 업데이트:

```
| 해냄 | ~~회의록 시스템 개발~~ | 2026-07-28 | 완료 ✅ |
```

할 일에 취소선이 생기고 상태가 "완료"로 표기됨

---

## ⚙️ 사전 준비

1. **Notion MCP 연결** (HANCOM 워크스페이스)
2. **스킬 설치**

---

## 💡 팁

- 할 일 내용은 정확하게 (부분 일치도 가능)
- 예: "회의록 개발" 입력하면 "회의록 시스템 개발"도 매칭
- 회의 진행 중에 완료된 것 곧바로 표기 가능
