# 회의록 → 캘린더 등록 스킬

Notion 회의록에서 **본인의 액션 아이템만** 읽어 Google Calendar에 자동으로 등록하는 스킬입니다.

---

## 🎯 목적

회의 후 `/meeting`으로 Notion에 저장된 회의록을 읽어, 내가 담당한 일들을 캘린더에 일정으로 등록합니다.

---

## 사용자

각 팀원 (개인별 실행)

---

## 사용 방법

### 명령어

```
/meeting-cal
```

또는: "캘린더 등록" / "내 할 일 캘린더에"

### 입력 정보

**1단계: 이름 입력**
```
해냄 (또는 소정, 하영, 유진)
```

**2단계: 회의록 선택**
```
최신
또는
2026-07-28
```

### 동작 원리

1. Notion D조_한컴 > 1.회의록에서 해당 회의록 찾기
2. "액션 아이템" 테이블에서 **담당자 = 입력한 이름**인 행만 추출
3. 기한이 있는 항목만 Google Calendar에 전체 일정 등록
4. 기한 "미정" 항목은 등록 건너뜀

---

## 📋 결과

등록이 완료되면:

```
✅ 캘린더 등록됨:
- 회의록 시스템 개발 — 2026-07-28
- 기획 아이디어 작성 — 2026-07-29

⚠️ 기한 미정 (미등록):
(없음)
```

Google Calendar의 내 일정에 자동으로 추가됩니다.

---

## ⚙️ 사전 준비

1. **Notion MCP 연결** (HANCOM 워크스페이스)
2. **Google Calendar MCP 연결**
3. **`/meeting` 스킬로 Notion 회의록 저장됨** (먼저 필요)

---

## 💡 팁

- 매주 월요일 아침 `latest` 선택해서 주간 일정 확인
- 기한 수정 시 Notion에서 먼저 수정, 그 후 `/meeting-cal` 다시 실행
- 같은 일정이 중복되면 Google Calendar에서 하나 삭제
