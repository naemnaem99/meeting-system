# 회의록 자동 정리 스킬

D조 팀의 회의 내용을 구조화된 회의록으로 정리하고 Notion에 자동으로 저장하는 스킬입니다.

---

## 🎯 역할

회의를 진행한 후, 회의 내용을 간단히 정리하면 Claude가 자동으로:
- 결정사항 추출
- 액션 아이템 정리 (담당자, 할 일, 기한)
- 논의 내용 요약

Notion D조_한컴 > 1.회의록에 저장합니다.

---

## 사용자

회의 정리 담당자 1명 (매 회의마다)

---

## 사용 방법

### 명령어

```
/meeting
```

또는: "회의록 작성" / "회의 정리"

### 입력 정보

**1단계: 회의 내용**
```
오늘 회의: 각자 회의록 시스템 개발 후 비교
- 4명이 각자 방식대로 회의록 시스템 설계·개발하기로 함
- 개발 완료 후 팀 내 비교 검토 예정
- 기획 아이디어도 동일하게 개별 작성 후 공유 예정

담당:
- 소정: 회의록 시스템 개발 (28일까지)
- 해냄: 회의록 시스템 개발 (28일까지), 기획 아이디어 (29일까지)
```

**2단계: 회의 날짜**
```
2026-07-28
```

**3단계: 참석자**
```
소정, 하영, 해냄, 유진
```

### 결과

Notion에 다음 형식으로 저장:

```
## 결정사항
- 각자 회의록 시스템을 개발하고 서로 비교 후 장점만 취합

## 액션 아이템
| 담당자 | 할 일 | 기한 |
|--------|-------|------|
| 소정 | 회의록 시스템 개발 | 2026-07-28 |
| 해냄 | 회의록 시스템 개발 | 2026-07-28 |
| 해냄 | 기획 아이디어 작성 | 2026-07-29 |

## 논의 내용 요약
- 각 팀원이 자신의 방식으로 설계·개발
- 개발 완료 후 팀 내 비교 검토
```
