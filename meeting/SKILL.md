## 회의록 자동 정리 스킬

### 팀 정보
- **팀원:** 소정, 하영, 해냄, 유진
- **Notion DB:** `collection://de7bdeac-d0b4-821e-96c7-0704ab267ee1` (HANCOM 워크스페이스 D조_한컴 > 1.회의록)

---

### 1단계: 입력 수집

사용자에게 다음을 요청한다:

```
회의 내용을 붙여넣어 주세요.
(메모, 대화 내용, 키워드 등 형식 무관)

그리고 아래 두 가지를 알려주세요:
- 회의 날짜 (예: 2026-07-27)
- 오늘 참석한 팀원 (소정 / 하영 / 해냄 / 유진 중)
```

---

### 2단계: 구조화 (핵심)

입력 텍스트를 분석해서 아래 3개 섹션을 추출한다. **결정사항과 액션 아이템을 최우선으로 정확하게 추출하는 것이 핵심이다.**

#### 결정사항
- "~로 결정", "~하기로 함", "~로 가자", "~로 확정", "그렇게 하자" 등 → 결정된 내용
- 여러 명이 동의한 내용 = 결정으로 간주
- 불확실하거나 논의 중인 내용은 여기 넣지 않는다

#### 액션 아이템
- "~가 맡기로", "~가 할 것", "~까지 완료", "담당: ~" 등에서 추출
- 담당자가 명확하지 않으면 문맥으로 추론 (팀원: 소정, 하영, 해냄, 유진)
- 기한이 언급되지 않으면 "미정"으로 표기
- 표 형태로 정리

#### 논의 내용 요약
- 결정되지 않은 논의, 아이디어, 보류된 사항, 다음 회의로 넘어간 내용
- 3~5줄 불릿으로 요약

---

### 3단계: 상태 판단

- 액션 아이템이 1개 이상 있으면 → `진행 중`
- 액션 아이템이 없으면 → `완료`

---

### 4단계: Notion 업로드

`mcp__claude_ai_Notion__notion-create-pages` 도구를 사용해서 다음 형식으로 페이지를 생성한다.

**parent:** `{ "type": "data_source_id", "data_source_id": "de7bdeac-d0b4-821e-96c7-0704ab267ee1" }`

**properties:**
```json
{
  "회의명": "YYYY-MM-DD 회의록",
  "날짜": "YYYY-MM-DD",
  "상태": "진행 중"
}
```

**content (Notion Markdown):**
```markdown
## 참석자

소정, 하영 (참석한 팀원 나열)

## 결정사항

- 결정 내용 1
- 결정 내용 2

## 액션 아이템

| 담당자 | 할 일 | 기한 |
|--------|-------|------|
| 소정   | ...   | ...  |

## 논의 내용 요약

- 논의 내용 1
- 논의 내용 2
```

---

### 5단계: 완료 보고

업로드 완료 후 사용자에게 다음을 보여준다:
1. 생성된 Notion 페이지 링크
2. 추출된 액션 아이템 요약 (담당자별)
